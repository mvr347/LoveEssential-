# GUI и конфигурация: схема 6

[Главная](../README.md) · [Конфигурация](MODULAR_CONFIGURATION.md) · [Табло](SCOREBOARD.md) · [Профиль](PLAYER_PROFILE.md)

## Что изменилось

- Возврат хранит контекст экрана, а не только его название. Вложенные разделы одного редактора различаются; пагинация каталога заменяет текущую страницу. Выбор фильтра или строки возвращает к существующему предку и не создаёт цикл «каталог → табло → каталог». Прямое открытие не добавляет родителя.
- Подписи, шаблоны, текстуры и данные карточек собраны в блоках соответствующих экранов `gui.yml`. Ссылки на старые ключи остались только в приватном индексе JAR. Общие сообщения и правила механики остаются в файле модуля.
- Карточки статистики, включая подкатегории и лор, находятся в `menus.profile-menu-statistics.categories`. Их переключение независимо; после закрытия страницы сбрасываются. Переключатели настроек находятся в `menus.profile-menu-settings.controls`.
- В `menus.sidebar-slots-title.rows` находятся шаблоны свободной, занятой и недоступной строки, а `slots` задаёт восемь позиций. При загрузке проверяются число позиций, уникальность и расположение внутри рабочей зоны. Стандартная сетка: `11, 12, 14, 15, 20, 21, 23, 24`.
- Пресет показывает состав, число доступных строк и предупреждение о замене. Недоступный пресет оставляет выбор без изменений. Инициализация не возвращает удалённые пресеты.
- Порядок `scoreboard.yml` закреплён: правила, header, separator, категории/каталог, footer, пресеты. Сохраняются комментарии и дополнительные поля существующих записей, включая текстуры/иконки, неизвестные типизированному API.
- Имена каталога с окончаниями `-key`/`-keys` защищены от ошибочного распознавания как ссылки на локализацию. Шаблоны, цвета и идентификаторы существующих плейсхолдеров не переоформляются.
- Создание NPC находится в рабочей зоне; пустой список использует 27 слотов с кнопкой по центру. При заполнении на странице помещаются 20 NPC и создание. ЛКМ сразу открывает мастер, ПКМ — подтверждение удаления; повторный промежуточный экран разделов убран. Список сортируется по видимому номеру. Обычные подсказки ввода используют этот номер, булевы значения и известные режимы в мастере переведены.

## Сохранность конфигурации

Перед переходом со схемы 5 создаются `.pre-gui6.bak` для существующих файлов модулей, GUI и основного конфига. Сначала разбираются и проверяются все документы, затем новые версии подготавливаются во временных файлах. Ошибка подготовки не изменяет активные файлы; ошибка последующей замены запускает откат уже заменённых документов. Постоянные резервные копии остаются для восстановления при внешней ошибке файловой системы, препятствующей и откату.

Старые пути настроек профиля и текстур поддерживает внутренний адаптер. Изменение по старому пути записывается в новое место; копии в обоих файлах не сохраняются. Если одновременно существуют разные значения в старом и новом месте, миграция отклоняется вместо выбора одного из них.

## Проверки и ограничения

Регрессии проверяют возврат со второй страницы каталога, выбор фильтра/строки без лишнего родителя, вложенные настройки, подтверждённое удаление NPC, независимое переключение статистики в обоих направлениях и её сброс после закрытия, удалённые/недоступные пресеты, пользовательские шаблоны и текстуры, старые пути API, резервные копии и повреждённый YAML. Отдельные тесты искусственно вызывают ошибку подготовки файла и ошибку после частичной записи; исходные документы восстанавливаются.

Maven verify на Java 25 с Paper API 26.2: 182 теста, 0 failures/errors/skips. Отдельно проверены 0–8 строк табло с длинной шапкой и footer, применение четырёх пресетов, 56 YAML на повторяющиеся ключи и ссылки документации. Исходные наборы шаблонов PAPI и локальные алиасы profile/TAB сверены с предыдущей версией без изменений. Визуальный прогон клиентом Minecraft на Paper/Purpur 26.2+ в этой среде не проводился: запущенного сервера и клиента нет. MockBukkit не подтверждает визуальное выравнивание шрифта или внешний вид при пользовательском ресурспаке.

## Уточнение размещения действий

Действия над содержимым не занимают шапку: удаление черновика NPC находится
рядом с полями, команды портала — в рабочей области. Лимит — 16 команд. «Показать всё»
в /display и продолжение черновика находятся в нижней строке. Настройки фона,
тени, интервалов, дальности и положения голограммы объединены в отдельный
компактный экран «Оформление». В шапке редактора остаются переходы между экранами.

Из каталога scoreboard удалена только карточка `placeholders.world`. При загрузке
существующего конфига перед удалением создаётся `.pre-world-line.bak`. Остальные
карточки, включая «Странствия», сохраняются; мировые PAPI-плейсхолдеры остаются
доступными для пользовательских строк и интеграций.

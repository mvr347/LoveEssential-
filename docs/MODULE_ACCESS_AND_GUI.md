# Миры, состояния и оформление меню

[Главная](../README.md) · [Команды](COMMANDS.md) · [Права](PERMISSIONS.md)

Настройки хранятся в `modules/<модуль>/<модуль>.yml`. Основной `config.yml` содержит общие параметры. Операционные данные, выбор игроков, определения объектов и черновики находятся в SQLite; тексты — в локальных `messages` файлов модулей.

## Ограничения использования

Пример для `modules/scoreboard/scoreboard.yml`:

```yaml
access:
  allowed-worlds: [world, 'survival_*']
  denied-worlds: ['arena_*']
  allowed-gamemodes: [survival, adventure]
  denied-gamemodes: [spectator]
  allowed-states: []
  denied-states: [combat, afk]
  required-states: [authenticated]
```

Пустые списки ничего не ограничивают. Запрет имеет приоритет, включая OP. Названия миров проверяются без учёта регистра; `*` означает произвольную последовательность, остальные символы буквальные. Проверяется текущий мир игрока, а не мир назначения телепорта. Для ограничения входа в мир дополнительно используйте настройки модуля worlds и территорий.

`allowed-states` требует хотя бы одно совпадение, `required-states` — все перечисленные состояния одновременно, `denied-states` блокирует при любом совпадении. Условия миров, режима и состояний применяются совместно. Новые ограничения добавляются к прежним ограничениям scoreboard, NPC и порталов; пустой `access` не отменяет их.

| ID состояния | Значение |
| --- | --- |
| normal | Нет боя, AFK, vanish, полёта, элитр, плавания, приседания, сна и транспорта |
| combat | Бой по сервису LoveCore |
| afk / vanished | Статус модулей LoveEssential |
| flying / gliding | Полёт / элитры |
| swimming / sneaking | Плавание / приседание |
| sleeping | Сон или поза /lay |
| vehicle | Игрок сидит на сущности или транспорте |
| ground / airborne | На земле / в воздухе |
| authenticated / unauthenticated | Состояние авторизации LoveAuth; без сервиса считается авторизованным |

Настройка через GUI: `/le module <модуль>` → «Ограничения использования». Состояния и режимы выбираются русскими кнопками, миры вводятся по имени или шаблону. ПКМ по записи удаляет её с подтверждением. Неправильный ID состояния, режим или тип списка отклоняется до записи конфигурации.

Правила проверяются для home/spawn/skin/afk/vanish, действий sit/lay/ride/hat, следов, сообщений, никнейма, профиля, инвентаря, крафта, выдачи стартового набора, переходов worlds, сценариев и открытия диалогов. У NPC ограничиваются видимость/взаимодействия и выбор целей наблюдения; у голограмм — показ и клики; у порталов — активация/частицы; у TAB/scoreboard — оформление. Проверки авторизации, приватности, территории и административных прав сохраняются.

Для уже созданных сидений и /lay проверяется мир/режим; состояния повторно не применяются, чтобы собственная посадка или поза сна не отменяла действие сразу. Бой, исчезновение опоры, выход и телепорт имеют отдельную очистку. Nightskip учитывает только подходящих игроков, joinquit — правила игрока, о котором сообщение. Серверный MOTD не имеет текущего мира/состояния игрока, секция access для него не предлагается. Настройка access не закрывает административные редакторы объектов.

## Оформление меню

Меню используют головы, серые рамки, пустые боковые стенки, отдельную строку навигации и кнопку назад в подменю. Реальные предметы остаются в редакторах крафтов, наборов и инвентаря. Восемь слотов scoreboard расположены двумя рядами по четыре и не заходят на края.

Для меню с поддержкой `gui.menus` можно заменить заголовки, lore, текстуры, видимость необязательных кнопок и позиции, сохранив их обработчики и проверки доступа. ID — исходный ключ заголовка из локальных `messages` модулей, где точки заменяются дефисами. Пример в `modules/profile/gui.yml` (без обёртки `gui:`):

```yaml
menus:
  profile-menu-title:
    size: 27
    title: '<gold>Мой профиль'
    buttons:
      '12':
        slot: 12
        enabled: true
        title: '<gold>Мои настройки'
        lore:
          - '<gray>Параметры чата, уведомлений и приватности'
          - '<dark_gray><st>─────────────────────'
          - '<green>ЛКМ <dark_gray>— <gray>открыть'
messages:
  profile-menu:
    settings: '<gold>Настройки'

```

Цвета и тексты находятся прямо в `title` и списке `lore`. Параметры кнопки: `enabled`, `slot`, `title`, `lore`, `texture`. Перенос сохраняет обработчик и права. «Закрыть» занимает последний слот; «Назад» — предпоследний и возвращает в реально открывавшееся меню. Небольшие экраны автоматически используют 27/36 слотов; сетки крафта и инвентаря сохраняют свою геометрию.

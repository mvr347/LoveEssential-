# Команды LoveEssential

[Главная](../README.md) · [Плейсхолдеры](PLACEHOLDERS.md) · [Права](PERMISSIONS.md) · [Руководство](ADMIN_GUIDE.md)

`<аргумент>` обязателен, `[аргумент]` необязателен; угловые скобки при вводе не нужны. Все команды из таблицы доступны через `/le`, включая алиасы: `/le home base`, `/le ник Аврора`. При конфликте используйте `/loveessential:loveessential home base`. TAB показывает доступные операции и значения. Для игровой команды нужны включённый модуль и авторизация LoveAuth, если этот сервис установлен.

## Панель и администрирование

| Команда | Назначение |
| --- | --- |
| `/le`, `/le menu` | Настройка и переключение модулей; нужно `loveessential.admin` |
| `/le help` | Каталог команд |
| `/le module` | Список модулей: ЛКМ — настройки, ПКМ — включение |
| `/le module <модуль> [settings]` | GUI настроек выбранного модуля |
| `/le module <модуль> enable` | Включить модуль с сохранением состояния в SQLite |
| `/le module <модуль> disable` | Отключить модуль |
| `/le module <модуль> info` | Показать состояние; для текстового ответа укажите `info` |
| `/le module <модуль> reload` | Перечитать конфиги и язык |
| `/le tab` | Настройки TAB |
| `/le tab export` | Экспорт в установленный TAB, копии `*.loveessential.bak` и `tab reload` |
| `/le reload` | Перечитать основной конфиг, файлы модулей и `lang.yml` |
| `/le integrations` | Состояние сервисов LoveCore |
| `/le backup` | Копия SQLite в `backups/` |
| `/le input <текст>` | Передать ответ активному GUI/мастеру; `cancel` отменяет ввод |
| `/le cancel <токен>` | Служебная команда кнопки отмены в чате; генерируется автоматически |

Управление модулями, TAB, reload, integrations и backup требует `loveessential.admin`. Большинство игровых команд выполняется от игрока. В консоли доступны административные операции, не требующие GUI, например `/le module npc disable`, `/le reload`, `/le backup`.

## Никнеймы

| Команда | Назначение |
| --- | --- |
| `/le nick` | Меню с предпросмотром, палитрой, градиентами и сбросами |
| `/le nick set Аврора`, `/le nick Аврора` | Изменить имя, сохранив оформление |
| `/le nick color gold` | Именованный цвет |
| `/le nick color #ff6699` | HEX-цвет |
| `/le nick gradient #ff6699 #ffcc66 #55ffff` | Градиент из 2–5 цветов |
| `/le nick color reset`, `/le nick gradient reset` | Сбросить только оформление |
| `/le nick reset` | Вернуть имя аккаунта и стандартное оформление |
| `/le nick player Alice set Аврора` | Изменить ник другого онлайн-игрока |
| `/le nick player Alice color gold` | Изменить его цвет; поддерживаются также `gradient` и `reset` |

Полный сброс в GUI требует подтверждения. Цвет по умолчанию задаётся в `modules/nickname.yml` через `default-color`; пустое значение позволяет наследовать цвет шаблона чата/TAB. Имя допускает Unicode-буквы, цифры и `_`; стандартная длина — 3–24 символа. Права на цвет, градиент и изменение другого игрока перечислены в [справочнике прав](PERMISSIONS.md). Команды выбора игрока используют настоящее имя аккаунта.

## Сообщения, профиль и инвентарь

```text
/le msg Alice Привет!
/le reply Привет!
/le ignore Alice
/le ignore
/le msgtoggle
/le profile Alice
/le profile list
/le invsee Alice view
/le invsee Alice edit
```

`ignore Alice` переключает игнор, а `ignore` открывает GUI, где можно убрать из списка и офлайн-игрока. Приём сообщений и игнор сохраняются в SQLite; текст переписки не записывается. Нажатие на входящее сообщение подставляет ответ его отправителю.

`invsee` работает с онлайн-игроками. Режим по умолчанию — просмотр; редактирование требует обеих нод `loveessential.invsee` и `loveessential.invsee.edit`. ЛКМ переносит/объединяет стек, ПКМ берёт половину или кладёт один предмет. В верхнем инвентаре: ряды 1–3 — основное хранилище, ряд 4 — хотбар, первые пять слотов ряда 5 — ботинки, поножи, нагрудник, шлем и вторая рука. Shift, цифры, двойные клики, клонирование, выбрасывание и drag заблокированы. Переносите предметы обычными кликами через курсор и собственный нижний инвентарь.

`profile` открывает профиль с текущим скином, разделами LoveAuth, LoveSubnames, LoveAdaptation и кнопкой `/rep`. `/profile settings` открывает настройки; `/profile hide|show|toggle` управляет доступом к профилю, `/profile activity hide|show|toggle` — отдельно к активности. Для имён, совпавших с подкомандами, используйте `/profile view <ник>`. Подробности: [профиль и приватность](PLAYER_PROFILE.md).

## NPC: создание и управление

Вместо `/le npc …` можно писать `/npc …`. ID — строчные латинские буквы, цифры, `_` и `-`, от 1 до 48 символов. Для работы мастера нужно `loveessential.npc.edit`; создание, публикация, удаление и другие операции имеют дополнительные права.

| Команда | Назначение |
| --- | --- |
| `/le npc`, `/le npc menu`, `/le npc list` | Список NPC и действия через GUI |
| `/le npc help` | Краткая помощь |
| `/le npc wizard` | Открыть/продолжить мастер |
| `/le npc create <id>` | Новый черновик NPC |
| `/le npc edit <id>` | Редактировать опубликованного NPC |
| `/le npc set <параметр> <значение>` | Изменить поле черновика |
| `/le npc here` | Позиция NPC в текущей точке |
| `/le npc page <1–7>` | Страница мастера |
| `/le npc save` | Сохранить черновик |
| `/le npc publish` | Проверить и опубликовать |
| `/le npc discard` | Отменить черновик |
| `/le npc preview` | Предпросмотр для редактора |
| `/le npc clone <id> <новый-id>` | Открыть копию как новый черновик |
| `/le npc enable <id>`, `/le npc disable <id>` | Включить/отключить NPC |
| `/le npc delete <id> confirm` | Удалить с подтверждением ID |
| `/le npc select` | Показать ID NPC под прицелом |
| `/le npc debug <id>` | Диагностика |
| `/le npc schedule <id>` | Страница расписания |
| `/le npc skin <id>` | Страница внешности; скин задаётся через `set skin` |
| `/le npc export <id>` | JSON в `exports/<id>.json` |
| `/le npc import <файл-без-расширения> <новый-id>` | Импорт как черновик; затем `publish` |

Например:

```text
/le npc create gate_guard
/le npc set name <gold>Страж ворот
/le npc set type MANNEQUIN
/le npc set skin Notch
/le npc set main-hand IRON_SWORD
/le npc here
/le npc publish
```

Параметры, диапазоны и примеры условий/действий находятся в [руководстве NPC](ADMIN_GUIDE.md#настройки-npc). TAB дополняет актуальный набор полей.

## NPC: маршруты

Команды изменяют активный черновик; индексы точек начинаются с **1**.

| Команда | Назначение |
| --- | --- |
| `/le npc path wizard [id]` | Открыть страницу маршрута; с ID — начать редактирование NPC |
| `/le npc path add` | Добавить текущую позицию |
| `/le npc path mode <ONCE\|LOOP\|PING_PONG\|RANDOM>` | Режим маршрута |
| `/le npc path point <N> wait <тики>` | Ожидание в точке |
| `/le npc path point <N> speed <число>` | Скорость |
| `/le npc path point <N> radius <число>` | Радиус достижения |
| `/le npc path point <N> position here` | Перенести точку в текущую позицию |
| `/le npc path point <N> condition <JSON>` | Условие |
| `/le npc path point <N> actions <JSON-массив>` | Действия |
| `/le npc path remove <N>` | Удалить точку |
| `/le npc path move <откуда> <куда>` | Переставить точку |
| `/le npc path undo`, `/le npc path redo` | Отмена/повтор |
| `/le npc path record` | Переключить запись движения |
| `/le npc path tool` | Получить инструмент добавления точки |
| `/le npc path show` | Показать точки частицами |
| `/le npc path test` | Запустить предпросмотр |
| `/le npc path pause`, `/le npc path resume`, `/le npc path step` | Управлять предпросмотром |

JSON для `path point … condition/actions` передавайте компактно, одним аргументом без пробелов. После изменений выполните `/le npc publish`. Предпросмотр виден редактору; действия точек при тесте не исполняются.

## NPC: диалоги

| Команда | Назначение |
| --- | --- |
| `/le npc dialog wizard [id]` | Страница диалога |
| `/le npc dialog node <узел> <текст>` | Создать/обновить узел |
| `/le npc dialog start <узел>` | Начальный узел |
| `/le npc dialog remove <узел>` | Удалить узел |
| `/le npc dialog answer <узел> <ответ-id> <следующий-узел\|end> <текст>` | Создать/обновить ответ |
| `/le npc dialog answer-condition <узел> <ответ-id> <JSON>` | Условие ответа |
| `/le npc dialog answer-actions <узел> <ответ-id> <JSON-массив>` | Действия ответа |

```text
/le npc dialog node hello <yellow>Чем могу помочь?
/le npc dialog answer hello leave end До встречи.
/le npc dialog start hello
/le npc publish
```

`/le answer <nonce> <узел> <ответ-id>` — служебная команда кнопок диалога; плагин генерирует её сам и проверяет сессию.

## Порталы и голограммы

| Команда | Назначение |
| --- | --- |
| `/le portal` | GUI порталов |
| `/le portal pos1` | Первый угол области |
| `/le portal create [id]` | Второй угол — текущая позиция |
| `/le portal destination <id>` | Назначение — текущая позиция |
| `/le portal delete <id>` | Удалить портал |
| `/le hologram` | GUI голограмм |
| `/le hologram create [текст]` | Создать с автоматическим ID, нижняя строка выше игрока |
| `/le hologram edit <id>` | Редактор строк, страниц, фона и предметов |
| `/le hologram info <id>` | Открыть актуальный редактор |
| `/le hologram addline <id> <текст>` | Добавить строку |
| `/le hologram move <id>` | Перенести на два блока выше текущей позиции |
| `/le hologram delete <id>` | Удалить голограмму |

Операции требуют `loveessential.admin`. Тексты голограмм сохраняются как ключи в `lang.yml`.

У NPC нет категорий или профессий. Используйте независимые параметры, диалоги и действия. Главная панель `/le` содержит только настройки модулей; управление NPC открывается через `/le npc`. Ввод можно отменить кнопкой в сообщении; после неверного значения запрос остаётся активным.


Подробные операции миров, примеры сценариев и условия переноса scoreboard: [руководство](WORLDS_AND_AUTOMATION.md).

Создание через GUI назначает ID автоматически для NPC, рецептов, порталов, сценариев и диалогов. Подробности посадки, следов, голограмм и API: [руководство](COMFORT_AND_HOLOGRAMS.md).

`/profile stats` (также `statistics`) открывает отдельное GUI полезной статистики. `/profile view <ник>` поддерживает сохранённые офлайн-профили. [Правила scoreboard и API временных табло](SCOREBOARD.md).

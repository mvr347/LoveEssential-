## Общее управление

`/le` и `/le menu` — только включение и настройка модулей, с `loveessential.admin`.
`/le module <модуль>` открывает настройки; `enable`, `disable`, `info`, `reload` управляют состоянием.
`/le tab` открывает редактор TAB. Подкоманды: `group <группа> <свойство> [значение]` и `player <ник> <свойство> [значение]` записывают свойство в `tab.yml` (без значения — удаляют); `reload` перечитывает конфигурацию; `debug <ник>` показывает группу и итоговые свойства с источниками; `parse <ник> <текст>` выводит текст так, как его увидит игрок; `cpu` показывает среднее время частей обновления за последние 10 секунд; `export` сохраняет эффективные группы, игроков и условия в `tab-export.yml`. Игроки могут использовать `/le tab nametag toggle` (скрыть чужие ники для себя) и `/le tab bossbar toggle` (скрыть полоски); администратор — `/le tab bossbar announce <полоска> <секунды>`. `/le reload`, `/le integrations`, `/le backup` — перечитывание конфигурации, сервисы и резервная копия SQLite.

`/le input`, `/homes`, `/tpa`, `/tpahere`, `/tpaccept`, `/tpdeny`, `/back` удалены. Ввод выполняется в диалоговом окне; мастер NPC также принимает чат с кнопкой [Отмена]. `/le cancel <токен>` — служебная команда этой кнопки.

## Профиль и ник

`/я`, `/профиль` — свой профиль; `/профиль Ник` — краткая сводка другого игрока. `/profile stats` — личная статистика, `/profile settings` — настройки.
`/profile hide|show|toggle` управляет профилем, `/profile activity hide|show|toggle` — видимостью активности отдельно.
`/nick set Аврора`, `/nick color #ff6699`, `/nick gradient #ff6699 #55ffff`, `/nick color reset`, `/nick reset` меняют свой ник и оформление. `/nick player Ник set Имя` требует `loveessential.nick.others`.

[Профиль](PLAYER_PROFILE.md) · [Scoreboard и жесты](SCOREBOARD.md) · [Порталы](PORTALS.md) · [Крафты](CUSTOM_CONTENT.md) · [Миры и сценарии](WORLDS_AND_AUTOMATION.md).

`/scoreboard` — личное меню табло, `/scoreboard toggle` — личное включение; `/le scoreboard show <табло> [игрок]` — временный показ именованного табло; `/le scoreboard edit` — административный редактор табло. Подробнее: [SCOREBOARD.md](SCOREBOARD.md).

## NPC: создание и управление

`/npc sel [номер]` выбирает NPC по взгляду или постоянному номеру. После выбора `/npc delete`,
`edit`, `info`, `skin`, `schedule`, `enable`, `disable`, `debug` и `export` работают без номера;
явный номер имеет приоритет над выбором. `/npc rename <имя>` переименовывает выбранного,
`&`-цвета поддерживаются. `/npc deselect` (алиас `снять`) сбрасывает выбор.

После выбора и `/npc info` появляются кнопки доступных действий: редактор, имя, скин, путь,
включение/выключение, удаление и снятие выбора. Кнопка имени подставляет команду для ввода текста;
остальные выполняют конкретное действие. Список `/npc list` открывается без технической выдачи в чат.

`/npc delete [номер]` показывает имя, номер и кнопки подтверждения/отмены. Запрос одноразовый,
действует 60 секунд и привязан к игроку, конкретному NPC и его ревизии. Смена выбора, выход,
истечение срока или удаление NPC отменяют запрос; изменение NPC требует нового подтверждения.
Вручную доступны `/npc delete confirm` и `/npc delete cancel`. Старый явный синтаксис
`/npc delete <номер> confirm` сохранён для совместимости. `/npc clone` открывает черновик копии
выбранного NPC с автоматически созданным внутренним ID; `/npc clone <номер>` копирует указанного,
а `/npc clone <источник> <новый ID>` сохраняется для явного задания нового ID.

`/npc import citizens [номер|all]` переносит NPC из `plugins/Citizens/saves.yml` (Citizens на сервере не нужен), пишет таблицу в `citizens-import.yml` и сам переставляет привязки LoveTweaks, LoveClans, LoveHunt и LoveContracts; LoveShops, стенды LoveLeaderboards и `npc_quests.yml` LoveContracts переставляются вручную по таблице.

Вместо `/le npc …` можно писать `/npc …`. В GUI и командах NPC доступны постоянные номера 1–999. Старые технические ID продолжают работать для совместимости; новые создаются автоматически. Для работы мастера нужно `loveessential.npc.edit`; создание, публикация, удаление и другие операции имеют дополнительные права.

| Команда | Назначение |
| --- | --- |
| `/le npc`, `/le npc menu`, `/le npc list` | Список NPC и действия через GUI |
| `/le npc help` | Краткая помощь |
| `/le npc wizard` | Открыть/продолжить мастер |
| `/le npc create [id]` | Новый черновик NPC |
| `/le npc edit [номер]` | Редактировать выбранного или указанного NPC |
| `/le npc set <параметр> <значение>` | Изменить поле черновика |
| `/le npc here` | Позиция NPC в текущей точке |
| `/le npc page <1–7>` | Страница мастера |
| `/le npc save` | Сохранить черновик |
| `/le npc publish` | Проверить и опубликовать |
| `/le npc discard` | Отменить черновик |
| `/le npc preview` | Предпросмотр для редактора |
| `/le npc clone <id> <новый-id>` | Открыть копию как новый черновик |
| `/le npc enable <id>`, `/le npc disable <id>` | Включить/отключить NPC |
| `/npc delete [номер]` | Запросить удаление выбранного или указанного NPC; подтвердить/отменить кнопкой в чате |
| `/le npc select` | Показать ID NPC под прицелом |
| `/le npc debug <id>` | Диагностика |
| `/le npc schedule <id>` | Страница расписания |
| `/le npc skin <id>` | Страница внешности; скин задаётся через `set skin` |
| `/le npc export <id>` | JSON в `exports/<id>.json` |
| `/le npc import <файл-без-расширения> <новый-id>` | Импорт как черновик; затем `publish` |

Например:

```text
/le npc create gate_guard
/le npc set name <gold>Страж ворот
/le npc set type MANNEQUIN
/le npc set skin Notch
/le npc set main-hand IRON_SWORD
/le npc here
/le npc publish
```

Параметры, диапазоны и примеры условий/действий находятся в [руководстве NPC](ADMIN_GUIDE.md#настройки-npc). TAB дополняет актуальный набор полей.

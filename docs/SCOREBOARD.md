# Боковая панель и временные табло Love

[Главная](../README.md) · [Команды](COMMANDS.md) · [Перенос LoveTweaks](WORLDS_AND_AUTOMATION.md#перенос-scoreboard-lovetweaks)

`/scoreboard` и `/le scoreboard` открывают личное меню на 36 слотов, также доступное через профиль → настройки → боковая панель. Отдельного права для личного выбора нет. Восемь соседних слотов 10–17 показывают точные base64-текстуры пустого и занятого места. Это явное исключение по запросу владельца из правила боковых стенок gui-gen-6.

| Действие | Результат |
| --- | --- |
| ЛКМ по пустому месту | Выбор строки с фильтрацией по категории, доступности и сортировкой |
| ЛКМ по занятому месту | Удалить строку; следующие сдвигаются, дырок нет |
| ПКМ по занятому месту | Выбрать замену |
| Shift+ЛКМ / Shift+ПКМ | Поднять / опустить строку с перестановкой соседей |
| ПКМ в каталоге | Следующий вариант оформления выбранной строки |

В шапке — личный переключатель, снизу — готовые наборы, назад и закрыть. Повторный выбор уже установленной строки переставляет её, не создавая дубликат. Личный выбор сохраняется в SQLite. Серверный каталог редактируется в файле модуля и через `/le scoreboard edit`; у каждого плейсхолдера есть отдельные варианты полного текста, цвета и условий. Символ `|` допустим внутри текста и не разделяет варианты.

`/scoreboard settings` (также `edit`) открывает отдельное административное меню. Здесь находятся редактор текстов/каталога, список миров с переключателями и переход к настройкам модуля. `/scoreboard worlds` сразу открывает миры. Нужен `loveessential.admin` (по умолчанию у OP). Редактор и список миров доступны даже при выключенном модуле; в шапке административного меню есть состояние и переключатель включения. Право на личное табло `loveessential.scoreboard` не требуется для административного редактора. Явный запрет `loveessential.admin` в менеджере прав действует и для OP. Из `/le` → настройки модуля scoreboard в этот редактор ведёт кнопка с книгой в шапке. Главное меню `/le` по-прежнему управляет модулями.

## Правила показа

Файл `modules/scoreboard/scoreboard.yml`:

| Настройка | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `refresh-ticks` | `20` | Обновление раз в секунду, диапазон 2–1200 тиков |
| `default-enabled` | `true` | Начальное состояние для игроков без сохранённых настроек |
| `disabled-worlds` | `[]` | Запрет показа в перечисленных мирах |
| `enabled-worlds` | `[]` | При заполнении разрешает показ только в этих мирах |
| `disabled-gamemodes` | `[]` | Скрывает в SURVIVAL, CREATIVE, ADVENTURE, SPECTATOR |
| `display-permission` | `''` | Дополнительное право для отображения; пусто — не требуется |
| `hide-while-afk` | `false` | Скрывает во время AFK LoveEssential |
| `hide-in-combat` | `false` | Скрывает во время боя по данным LoveCore |
| `max-selected-lines` | `8` | Дополнительный предел выбранных строк, 1–8 |
| `overrides.allow-forced` | `true` | Разрешает API-запросам с `force=true` обходить личное выключение |
| `overrides.max-seconds` | `600` | Максимальная длительность запроса, 1–86400 секунд |
| `overrides.per-player-limit` | `8` | Одновременные запросы на игрока, 1–32 |

Имена миров сравниваются без учёта регистра. Запреты из файла модуля и из GUI редактора **складываются**; разрешающий список их не отменяет. Запрет файла отмечен в GUI и изменяется через настройки модуля. В GUI списка миров переключатели записываются в SQLite. Список включает загруженные миры и имена из правил, поэтому запрет незагруженного мира тоже можно снять. Табло не отображается до авторизации.

Например:

```yaml
disabled-worlds: [arena, world_the_end]
disabled-gamemodes: [SPECTATOR]
hide-in-combat: true
```

Редактор каталога задаёт заголовок, разделитель, нижнюю строку, максимум строк, варианты и PAPI-требования. Оформление и тексты каталога находятся прямо в `modules/scoreboard/scoreboard.yml → catalog`; SQLite хранит зеркало каталога, историю и личный выбор. После правки файла используйте `/le reload`; GUI-редактор сохраняет туда же. Действует меньший из двух лимитов строк: в файле модуля и в каталоге. Minecraft допускает максимум 15 физических строк; разделители тоже занимают строки.

## API для событий, арен и заданий

`ScoreboardService` регистрируется в Bukkit ServicesManager. Это основа для будущих интеграций Love-плагинов: сами эти плагины должны вызвать API в нужный момент. Все вызовы сервиса и его handle выполняются на основном потоке сервера.

```java
var service = Bukkit.getServicesManager().load(ScoreboardService.class);
if (service != null) {
    var lease = service.show(
        this, player.getUniqueId(), 100, Duration.ofMinutes(3), true,
        new ScoreboardService.Board(
            Component.text("Арена"),
            List.of(Component.text("Раунд 1"), Component.text("Осталось: 03:00"))));

    lease.update(new ScoreboardService.Board(
        Component.text("Арена"), List.of(Component.text("Раунд 2"))));
    // В конце события:
    lease.close();
}
```

Тексты примера соседний плагин получает из своей локализации. `Board` содержит заголовок и 1–15 готовых Adventure Component; плейсхолдеры внутри них автоматически не вычисляются. Диапазон приоритета — от −1000 до 1000: побеждает больший, при равенстве — более новый запрос. `update` меняет содержимое без продления срока. После окончания запроса возвращается следующий активный запрос либо личное табло. Личный выбор в SQLite не изменяется.

Запрос автоматически удаляется по сроку, при выходе игрока или отключении владельца-плагина. `close` можно вызывать повторно; обновление завершённого запроса отклоняется. При отключении LoveEssential все запросы освобождаются; после его перезагрузки соседнему плагину нужно заново получить сервис. Дополнительно действует общий предел 4096 запросов.

Принудительный показ соблюдает запреты миров/режимов, авторизацию, дополнительные права и правила AFK/боя. `force=false` учитывает личный переключатель всегда; `force=true` может его обойти только при разрешённой настройке. API не захватывает чужой scoreboard и не уничтожает команды имён TAB. Совместимость с внешним TAB требует настройки его доски отдельно; API управляет нативной боковой панелью LoveEssential.

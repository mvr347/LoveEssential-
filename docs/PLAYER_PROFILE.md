# Профиль игрока и приватность

[Главная](../README.md) · [Команды](COMMANDS.md) · [Плейсхолдеры](PLACEHOLDERS.md)

`/я`, `/профиль` и `/profile` открывают собственный профиль. `/профиль Ник` или `/profile view Ник` открывает доступный профиль другого игрока, в том числе сохранённый офлайн. Для неизвестного игрока данные не выдумываются: он должен хотя бы раз зайти с работающим модулем.

## Собственный профиль

Пять разделов: **Безопасность, Настройки, Поведение, Статистика, Адаптации**. Безопасность ведёт в собственный LoveAuth, настройки содержат приватность, уведомления, сообщения, чат, персонализацию и scoreboard. Поведение сразу открывает собственное меню LoveBehavior; Адаптации сразу открывают `loveadaptation mainmenu`. Промежуточных экранов LoveEssential нет. Встроенного просмотра инвентаря в профиле нет; администрация использует отдельный `/invsee`.

Статистика устроена как «сводка → подробности категории». «Мир и выживание» раскрывает время/визиты, движение, добычу и бои. «Хозяйство» — рыбалку, животных, жителей и кошелёк. При установленных плагинах добавляются дуэли, охота, контракты и активности. У каждой категории есть несколько карточек подробностей и кнопка назад. `/profile stats` сразу открывает сводку.

Minecraft-счётчики реальные: часы, смерти, убийства, K/D, урон, километры, добыча, рыбалка и сделки. Агрегаты добычи обновляются не чаще раза в 30 секунд. Счётчик использования предметов-блоков включает другие действия и не обозначается точным количеством установленных блоков.

Дополнительные показатели настраиваются в `modules/profile/profile.yml → statistics.placeholders` и `statistics.categories`; тексты — `modules/profile/gui.yml → texts.profile-stats`. Поддержаны реальные PAPI-идентификаторы:

| Плагин | Примеры |
| --- | --- |
| [LoveDuels](https://github.com/mvr347/LoveDuels) | loveduels_honor, wins, losses, winrate, streak, best_streak, money_won |
| [LoveHunt](https://github.com/mvr347/LoveHunt) | lovehunt_rank, rating, completed, failed, reward_modifier |
| [LoveContracts](https://github.com/mvr347/LoveContracts) | lovecontracts_total_completed, total_failed, total_accepted, daily_completed, success_rate, current_streak, best_streak |
| [LoveActivities](https://github.com/mvr347/LoveActivities) | loveactivities_wins_total, losses_total, winrate_total, won_money_total, lost_money_total |

В каждой строке таблицы общий префикс относится ко всем перечисленным суффиксам. Значения читает PlaceholderAPI от лица владельца профиля. При отсутствии плагина категория по умолчанию скрыта; отсутствующие данные обозначаются «—», нули не подставляются вместо недоступной интеграции.

## Чужой и офлайн-профиль

Другие видят краткую сводку без переходов в личные подробности. В шапке расположены репутация и жалоба; данные скина относятся к выбранному игроку. Репутация запускает настоящий `/rep Ник` LoveBehavior с его проверками, без прямого изменения показателей через API. Для офлайн-игрока оценка недоступна.

Жалоба открывает диалог с причиной; сохраняется в SQLite с задержкой между отправками. `/reports` или `/жалобы` — административная очередь с отметкой рассмотрения. Жалоба не снимает репутацию автоматически. Самому себе жаловаться нельзя.

Офлайн-просмотр читает последний снимок из SQLite асинхронно: сохранённую текстуру скина и общие показатели. PAPI зрителя не используется вместо отсутствующего игрока. Для старых снимков новые показатели становятся доступны после следующего входа. Сеть Mojang при открытии сохранённого профиля не запрашивается.

## Два переключателя

`Профиль → Настройки → Активность и приватность` содержит независимые параметры:

| Действие | Команда |
| --- | --- |
| Скрыть/открыть весь профиль | `/profile hide`, `/profile show`, `/profile toggle` |
| Явная приватность | `/profile privacy private`, `/profile privacy public` |
| Скрыть/открыть активность | `/profile activity hide`, `/profile activity show`, `/profile activity toggle` |

Скрытый профиль исключается из списка и дополнения имён. Скрытие активности закрывает чувствительную сводку времени/визитов, сохраняя остальные общие категории. OP не обходит приватность. Настройки хранятся в SQLite и действуют офлайн. Разрешение повторно проверяется при действии и обновлении открытого меню.

PAPI: `%loveessential_profile_visible%`, `%loveessential_profile_hidden%`, `%loveessential_activity_enabled%`, `%loveessential_activity_visible%`, `%loveessential_profile_command%`, `%loveessential_profile_toggle_command%`. Точная семантика — в [справочнике](PLACEHOLDERS.md).

Головы карточек используют исходные base64 `textures.value` из примеров (`profile.gui.textures`, в файле `modules/profile/gui.yml → textures`), шапка — скин выбранного игрока. Настройки выводятся по-русски, исходные yes/no из PAPI сохраняются для внешних проверок. Оформление и допустимые размеры меню описаны в [настройках GUI](MODULE_ACCESS_AND_GUI.md).

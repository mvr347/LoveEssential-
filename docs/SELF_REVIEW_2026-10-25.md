# Проверка изменений PR #33 и #34

Проверена интеграция GUI-ветки с `main` после слияния аддона DeluxeCombat
(`890c471`). Это повторный просмотр кода, проверка миграции и тесты, а не
сертификация совместимости с коммерческим серверным плагином.

## Исправлено

- Конфликты README и ReviveTest объединены с сохранением описания аддона,
  аудита и обеих групп тестов. Проверка закрытия обыска сохранена для слота 53.
- Удалена недостижимая пагинация команд портала: валидация ограничивает число
  команд 16, поэтому страницы по 20 не нужны. Действия остаются в рабочей области;
  при заполнении всех 16 мест кнопка добавления больше не предлагает невозможную
  операцию.
- Закрытый CombatBridge больше не принимает mark/clear/publish через сохранённую
  внешним плагином ссылку. Раньше после выгрузки можно было снова заполнить кэш
  и изменить исходную службу LoveCore. Добавлен регрессионный тест сохранённой
  ссылки: ни метка ядра, ни очередь untag после закрытия не изменяются.
- Проверка прав god больше не принимает синхронное стандартное сообщение о входе
  MockBukkit за ответ команды. Очередь сообщений очищается до выполнения команды;
  проверки её ответа и фактической защиты от урона сохранены.

## Дополнительно просмотрено

- Маршруты кнопок после перемещения/уплотнения GUI, ревизии голограмм и возврат
  из отдельного оформления; связь новых подписей с конфигом модуля.
- Удаление только карточки мира, резервная копия и повторный запуск миграции;
  остальные карточки, включая «Странствия», сохранены.
- Снятие регистрации CombatState, остановка задач, поколение отложенных
  обработчиков, граница между основным потоком и опубликованными снимками.
- Приоритеты события падения, подтверждение состояния перед меткой,
  исключение дуэлей/авторизации/vanish и ограниченная атрибуция таймерной смерти.
- Аддон не создаёт трупы и не копирует предметы; модель и лут Corpses остаются
  ответственностью штатных обработчиков DeluxeCombat.

## Границы проверки

Живого Paper/Purpur с JAR DeluxeCombat нет. Визуальное поведение, внутренний
порядок его слушателей, обыск трупа, combat-logout и точный баланс предметов
не проверены. Исходные количественные замеры heap/JFR и TPS не проводились;
снижение памяти или нагрузки в процентах не заявляется. Подробные риски интеграций
и серверная матрица остаются в REVIVE_COMBAT_AUDIT.md и README аддона.

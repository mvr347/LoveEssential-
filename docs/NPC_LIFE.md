# Поведение NPC: распорядок, характер и занятия

NPC остаётся одной сущностью с несколькими ролями. LoveContracts забирает только квестовое взаимодействие конкретного игрока;
LoveBrew продолжает обслуживать остальных. Shift+ПКМ пропускает квестовую роль, позволяя обратиться к обычной профессии.
NPC не получает искусственных уровней или опыта.

## Распорядок

Настройки доступны существующему NPC-редактору, импорту и API:

```yaml
routine-enabled: 'true'
work-from: '0'
work-to: '12000'
off-duty: walk
```

Это значения `NpcDefinition.settings`, не отдельный раздел глобального конфига.
Во время смены NPC возвращается в сохранённую точку spawn и остаётся там.
После смены `walk` использует настроенный маршрут, `away` скрывает NPC до следующей смены.
Для прогулки нужно задать маршрут, например LOOP или PING_PONG. Без точек NPC остаётся на месте.
Смена поддерживает переход через полночь; одинаковые начало и конец означают круглосуточную работу.
Диапазон полуоткрытый: начало включено, конец исключён. Время — игровые тики мира, 0 соответствует 06:00 Minecraft.
Старые `enabled-hours`, `hour-from`, `hour-to` остаются дополнительным ограничением видимости.
Результат поиска пути от предыдущей смены отбрасывается. Валидное взаимодействие приостанавливает движение, включая квестовые клики.

## Диалоги и отношение

`dialog-friendly`, `dialog-fearful`, `dialog-skeptical` задают ID начальных узлов существующего диалога.
Узлы должны существовать; редактор валидирует ссылки. Если настройка не задана, используется обычный `dialog.start`.
Стиль игры 0 выбирает fearful; вежливость 0–1 — skeptical; вежливость или стиль 5–6 — friendly.
Отсутствие BehaviorLevels означает нейтральное отношение.

Для выбора допустимых действий в ответах добавлено условие:

```json
{"type":"npc-disposition","args":{"value":"friendly"},"children":[]}
```

Возможные значения: `friendly`, `fearful`, `skeptical`, `neutral`. Условия перепроверяются при выборе ответа.
Так можно оставить нейтральный разговор всем, а особое поручение или приглашение к игре — только подходящим игрокам.
Не блокируйте все обязательные квестовые ответы для плохой репутации: оставляйте путь исправить отношения делом.

Профессию, беседу и занятия можно связать существующими ответами диалога и действиями `command`.
Команды выполняются от игрока с его правами и проверяются по `actions.allowed-player-commands`; консольные привилегии не выдаются.
При использовании сторонней мини-игры явно укажите её плагин и команду в разрешённом списке. Новая азартная игра с NPC-ботом здесь не вводится.

Проверки: JUnit `NpcRoutineTest` проверяет границы дневной/ночной смены и выбор отношения.
Для проверки движения, профессий и диалогов нужен тестовый Paper-сервер со всеми тремя обновлёнными плагинами.

# Книга тайн (модуль `secrets`)

Список пасхалок, которые игрок уже нашёл. Открывается командой `/secrets` (`/тайны`) и в списке модулей
`/le module`. Найденная тайна показана с названием, описанием и датой, ненайденная — серым «?» с
подсказкой; внизу шкала прогресса из 16 клеток. Награды за находку модуль не выдаёт.

## Как плагины отмечают находку

Через сервис `SecretBook` из LoveCore: `discover(игрок, "идентификатор")` возвращает `true` только в
первый раз. Событие `SecretDiscoveredEvent` получает любой плагин, который хочет что-то выдать
(например, титул через LoveSubnames). Неизвестный идентификатор игнорируется и один раз попадает в лог.
Пока список игрока ещё не пришёл из базы (первые мгновения после входа), `discover` ничего не
записывает и отвечает `false`.

## Каталог

`modules/secrets/secrets.yml`, раздел `catalog`. Порядок в файле — порядок в книге. У каждой тайны
`name`, `hint` (до находки), `description` (после) и `icon` (предмет из Material; неизвестный заменяется
книгой). Тайны, о которых плагин-источник не знает, в книге просто остаются «?».

| Идентификатор | Где спрятана |
|---|---|
| `toast` | LoveBrew: чокнуться с другим игроком |
| `legendary_aging` | LoveBrew: напиток, выдержанный в бочке игровой год |
| `perfectionists` | LoveClans: сундук клана, где все ячейки забиты одним предметом по 64 |
| `same_for_same` | LoveTrades: обмен точно такими же предметами |
| `anniversary` | LoveAuth: вход в годовщину регистрации |
| `nine_lives` | LoveEssential, `revive`: третий подъём за одну жизнь |
| `debt_repaid` | LoveEssential, `revive`: вас поднял тот, кого вы сами поднимали |
| `western` | LoveDuels: оба упали в дуэли одновременно |

## Хранение

Один документ `secrets` на игрока в SQLite (идентификатор → время находки в миллисекундах). Список
загружается при входе и освобождается при выходе.

## Плейсхолдеры

`%loveessential_secrets%` и `%loveessential_secrets_total%` (см. [PLACEHOLDERS.md](PLACEHOLDERS.md)).

## Пасхалки подъёма

Две пасхалки живут в модуле `revive` и выключаются ключом `revive.easter-eggs`: фраза при третьем
подъёме за одну жизнь (счётчик обнуляется настоящей смертью) и фраза, когда вас поднял игрок, которого
вы сами поднимали. Список «кого я поднимал» хранится в памяти и обнуляется при перезапуске сервера.

# Размещение путевых столбов VoidCore

Скопируйте `resourcepack` поверх `plugins/ItemsAdder/contents/voidcore/resourcepack`.
Перед заменой сохраните прежние восемь JSON вне папки ресурспака. Конфиги и PNG не заменяются.
Используйте LoveEssential с настройками размещения, выполните `/iazip` и примите обновлённый пак.
Переустанавливать уже созданные столбы не требуется.

В моделях добавлен `display.fixed.scale: [2, 2, 2]`; из определений предметов удалён
`transformation`. ID, все 119 кубов, UV, повороты и ссылки на PNG сохранены.
Режим ItemDisplay для этих пресетов — `FIXED`. Для произвольных моделей доступны свои
высота, смещение, масштаб, размер подписи и область нажатия в `/le waystone models`.

Высоты: 1.70625 / 2.01875 / 2.33125 / 2.70625 блока; подпись выше на 0.25 блока.
Проверено расчётом всех вершин: нижняя точка каждого варианта находится на Y=0.
Визуальная проверка требует настоящего клиента Minecraft 26.2+.
